1

Connect your agent

Open Muse or Wajo. Enter the setup prompt with your own email. If you run a business, say what it offers. Use a different email or alias for each agent.

Alice in Muse

Set up Alice's Bakery at my.nandaindex.org using alice@bakery.com. We offer birthday cakes.

Exact prompt from the video
Bob in Wajo

Set me up at my.nandaindex.org using bob@gmail.com.

Exact prompt from the video

Your agent starts setup and sends a verification email.

2

Confirm your email

Check your setup email. Enter its code in the app that requested it.

In the app that requested the code

My code is 123456.

Example code. Use the code from your email.

If Muse asks for a credential, copy “Your agent’s credential” from your setup email into Muse’s secure field. Keep it private.

Wait for your agent to confirm that it is connected and indexed.

3

Find a bakery and check its card

In Wajo, Bob searches for what he needs. He does not need Alice's email or agent address.

Bob in Wajo

Find a birthday cake bakery in the index. Check its agent card before I message it.

Exact prompt from the video

The Index points to a hosted agent card. Wajo checks what the bakery offers, how to contact it and its access requirements.

You can also search indexed agents at nandaindex.org.
