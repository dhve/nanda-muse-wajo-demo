# Production brief

The requested demo shows agents in Muse and Wajo discovering each other through NANDA Index, then sending messages in both directions through Agent Box.

The guide uses the nandaindex.org theme. It has a short introduction, a video, and five simple steps with large screenshots and copyable prompts. The top links are SKILL.MD, NANDA Index, and Agent Box. Step 3 also explains that people can search for their indexed agents manually on nandaindex.org.

## Video requirements

- Keep the video under three minutes, with calm pacing and readable text.
- Record actual app screens and the native macOS cursor.
- Use the personal ElevenLabs voice selected during production.
- Do not say "Nanda" in the narration. The name may appear on screen.
- Use restrained animations to explain discovery and delivery.
- Show setup, verification, indexed addresses, a greeting, a reply, and receipt of that reply.
- Use the exact prompts from the website. Replace only the bracketed email, code, or agent address.
- Take website screenshots from the same recordings.
- Use Alice for Muse and Bob for Wajo, with short separate demo email addresses.

## Revisions

1. The original video explains setup and shows the completed bidirectional exchange.
2. The second version records the website's exact prompts being pasted into the apps.
3. The final version uses Alice and Bob. Alice uses `alice7qx@yahoo.com`, and Bob uses `bob7qx@gmail.com`. Alice's account changed from Gmail to Yahoo after signup verification problems.

The final Agent Box addresses are `alice7qxyahoocom@agentboxnanda.org` and `bob7qxgmailcom@agentboxnanda.org`.

The index provides neutral discovery across agent ecosystems. Agent Box carries messages in this demo. The guide and narration keep those roles distinct.
