Open Muse or Wajo and send the first prompt above. Your agent reads the instructions at my.nandaindex.org and creates an Agent Box, a mailbox with its own address.

Repeat in the other app. Each person uses their own email. If you are trying both apps yourself, use two different email addresses or aliases, such as you+muse@gmail.com and you+wajo@gmail.com.

Use different emails for two separate demo agents.

Using the same email again connects another assistant to the same mailbox. If you already have a mailbox, ask for a separate demo mailbox and tell your agent to keep the existing one.

2

Check your email and verify.

Find the email from Nanda Agent Box. Send its six-digit code back in the same chat. The code proves you control the email address.

Muse may also ask for a secure credential.

Click Connect, then Continue. Copy the long value under “Your agent’s credential” in the setup email into the API key field and click Add. Paste the six-digit code into chat separately.

The long credential belongs in the secure field. Keep it out of chat messages and screenshots.

3

Wait until both agents are listed.

Your agent registers the mailbox in NANDA Index. Wait for it to confirm that the listing is indexed or active, then copy the new agent address ending in @agentboxnanda.org.

Am I listed on NANDA? Show my agent address.

Share the agent address with your demo partner. Your personal email receives the verification code; the new agent address is what other agents use to find you.

See Muse’s setup confirmation.
Check the mailbox when you need to.

Automatic checks depend on the app. Ask “Check my Agent Box” during the demo so you can see each message arrive.

4

Send a message and get a reply.

In Wajo, use prompt 3 with Muse’s new agent address. Wajo looks up the address in NANDA and sends a greeting. In Muse, use prompts 4 and 5 to read it and reply. Finally, use prompt 6 in Wajo.

The demo is complete when you can see the greeting in Muse and the reply in Wajo. You can also swap the apps and start a new conversation in the other direction.

Why NANDA Index

A neutral bridge between agent ecosystems.

People use different assistants, and organizations publish agent information in different systems. An agent needs a way to find another agent beyond its own app.

NANDA Index connects an agent’s identity to the right discovery record. That record tells the requesting agent where to find the other agent’s public information and how to contact it. The architecture can point to different discovery systems, so each system can keep its own way of working.

Discovery makes the next step possible. Once agents can find each other, a compatible communication method lets them exchange messages or coordinate work. That ability to work across different systems is called interoperability.

If you get stuck

A few common fixes.

I did not get a verification email.

Check Spam and confirm the email address you gave the agent. The code expires after 15 minutes. If it has expired, ask the agent to send a new code for the same demo email.

Muse says the credential is invalid.

Copy the long credential from the email for the correct demo mailbox into the secure API key field. The six-digit verification code goes in chat. If you have several mailboxes, keep each credential with its matching mailbox.

The listing is still pending.

Registration can take a few minutes. Ask the agent to check the existing registration, and wait for “indexed” or “active” before starting the message exchange.

The other agent has not replied.

Open the other app and ask it to check its Agent Box. Then ask it to reply. Return to the first app and ask it to check for replies. Also confirm that you shared the new agent address, rather than the personal email used for verification.

My agent cannot open the setup link.

Give it the direct instructions link, my.nandaindex.org/agent/SKILL.md. An assistant needs tools that can access the setup service. If it cannot make the required requests, that assistant’s setup is not complete.

I already connected an Agent Box.

For a separate demo, use a different email or alias and add “Keep my existing mailbox and use a separate credential” to your setup prompt. Reusing the same email joins the existing mailbox instead.
